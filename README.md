# AI Assistant Frontend

This is the frontend for the AI Assistant application, built with React and Vite. It provides a user interface for interacting with AI models, managing documents, and viewing user profiles.

## ✨ Features

*   **Dashboard:** Overview and main entry point.
*   **AI Chat:** Interactive chat interface.
*   **Document Management:** Section for handling documents.
*   **User Profile:** User profile and settings.
*   **Responsive Sidebar Navigation:** Easy navigation between different sections of the application.

## 🛠️ Tech Stack

*   **Framework:** [React](https://reactjs.org/)
*   **Build Tool:** [Vite](https://vitejs.dev/)
*   **Routing:** [React Router](https://reactrouter.com/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Icons:** [React Icons](https://react-icons.github.io/react-icons/)

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js (v18 or newer) and npm installed on your machine.

### Installation

1.  Clone the repository.
2.  Navigate to the project directory:
    ```bash
    cd frontend
    ```
3.  Install the dependencies:
    ```bash
    npm install
    ```

### Running the Development Server

To start the development server, run the following command:

```bash
npm run dev
```

Open your browser to the local URL provided in the terminal to see the application.
